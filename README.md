# 焦げない台所 - Kogenai Kitchen

「時短の逆をいく。丁寧に作る、本格派の家庭料理。」をコンセプトにした料理サイトです。

### 制作概要
* **制作期間**: 約10日
* **役割**: 企画 / デザイン / コーディング
* **公開URL**: https://kogenai-kitchen.vercel.app/
* **使用技術**: HTML / CSS / JavaScript / Git / GitHub / Vercel

### 設計・実装のこだわり
* **CSS変数による一元管理**: 余白、タイポグラフィ、カラーパレットをCSS変数で定義し、メンテナンス性と一貫性を担保しました。
* **独自CSS設計**: フレームワークの制約から脱却し、サイトの世界観（余白、文字組み）を忠実に再現するために独自CSSで設計。保守性を意識し、共通部品（common.css）とページ別CSSを分離しました。
* **ユーザー体験への配慮**: 
  * **料理中の使いやすさ**: PC版は材料と工程を並列配置。スマホ版はタブUIで情報を最適化。
  * **印刷対応**: レシピを印刷して台所に持ち込めるよう、専用の印刷用CSS（@media print）を実装し、不要な装飾を排した可読性の高いレイアウトに調整しました。
* **読み物としての設計**: レシピ（グリッドレイアウト）とコラム（横長カード）でUIを分け、「探す」と「読む」の体験を明確に差別化しました。

### 技術的な挑戦と学び
フレームワークの干渉問題に直面した際、安易な修正で済ませず「CSS設計そのものの見直し」を選択しました。結果として、共通クラスの定義や変数の活用など、**「再利用性を意識したCSS設計」**の実装能力が大きく向上しました。
